## Audit artifacts and redistribution gates

The 2026-11-09 audit used scratch artifacts under
`/tmp/joinery-snowflake-license-audit/` and
`/tmp/joinery-snowflake-driver-prototype/`; those paths are historical and are
not the current review locations. Current evidence is in the ignored local
cache `.cache/verification/snowflake-licenses/`, including the exact registry
metadata and tarballs, tag source snapshots, provenance/tree evidence, and the
verbatim notice texts `asn1.js-MIT-v5.0.1.txt` and
`proxy-agents-MIT-1.1.0-shared.txt`. These cache files are scratch evidence,
not repository package notices. The RFC2560 release mapping is reproducible
from `asn1.js-rfc2560-release-mapping.json` and the three corresponding release
snapshots in that cache: compare both extracted npm files byte for byte with
the immutable release sources, and compare the complete LICENSE with the cached
notice. The earlier main-package tag snapshot remains evidence of why that tag
alone was insufficient.

The actual staged runtime is `.cache/snowflake-runtime/macos-arm64/` with
manifest SHA-256 `1a7b068a85f4d085c8415b8fd6256acb54b803ab0e22b668068541de26bb182d`.
Its manifest records 183 packages and still reports
`asn1.js-rfc2560@5.0.1`, `asn1.js-rfc5280@3.0.0`, and
`proxy-agent-negotiate@1.1.0` as lacking a root notice file. The external
evidence above does not alter that stage; no additional notices have been
added to it. The staged Node 24.22.2 binary SHA-256 is
`b6fb419f0f43bb2fbca273700294dd2f3b685a64b60e8417c295f47646a70e4a`.

Before redistributing an application bundle:

1. Include the applicable original SDK, dependency, and Node runtime license
   and notice text. Review the shared-notice provenance for
   `proxy-agent-negotiate` and preserve the RFC2560 provenance limits.
2. Re-run inventory against the exact final lock and packaged files, including
   platform-specific Node binaries and any native/runtime components. Confirm
   that required notices are actually shipped with the product.
3. Review the final dependency tree and distribution obligations. This audit
   does not establish legal clearance or whether a package is reachable in a
   particular application path. No npm lifecycle scripts were run for the
   scratch audit.

Until those steps are complete, neither SDK selection nor these findings
constitute approval to redistribute a production package.
